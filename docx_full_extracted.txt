MASTER BUILD PROMPT — Adaptive Learning Engine
You are the lead software architect, senior full-stack engineer, AI/ML engineer, database architect, UX engineer, and DevOps engineer responsible for building a production-quality Adaptive Learning Engine (ALE).
Do not build a conventional LMS, course platform, chatbot, or simple AI tutor.
Build a personal/adaptive learning operating system whose purpose is:
Take a learner from “I want to master X” to independent competence as efficiently as possible by continuously modeling what they know, detecting weaknesses, selecting the next best learning action, generating/adapting learning activities, collecting evidence, and updating the learner model.
The system must work for arbitrary knowledge domains such as programming, mathematics, medicine, engineering, languages, science, business, etc.
The architecture must support:
Public web usage
Personal Windows desktop usage
Android usage
Offline learning
Online synchronization
Multiple AI providers
Future native/mobile/desktop expansion
Future multi-user/public deployment

PART 20 — CANDIDATE SCORING
For each candidate learning target calculate:
candidate_score =
    0.25 * goal_relevance
  + 0.20 * weakness
  + 0.15 * prerequisite_value
  + 0.15 * retention_need
  + 0.10 * context_continuity
  + 0.10 * skill_importance
  + 0.05 * curiosity
Where:
weakness = 1 - mastery
Calculate retention using an initial forgetting model:
retention =
exp(-forgetting_rate * days_since_last_evidence)
Then:
retention_need = 1 - retention
These weights must be configurable.
Do not hard-code them throughout the application.
Create an AdaptiveEngine configuration object.
